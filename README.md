## 🎯 主要功能

### 1. 课程学习支持
- 课程内容参考
- 课程资料管理（讲义、作业、测验等）**可以放在本地目录下,创建自己的知识库,pdf请自行下载**

## 📝 使用注意事项

1. **PDF 文件不包含在版本控制中**
   - 原始 PDF 课程材料存储在本地
   - 仓库中不上传 PDF 文件以避免版权问题
   - 只提取和分享课程结构化信息

2. **遵循学术诚信**
   - 本 Skill 是学习辅助工具，不是作业代写工具
   - 所有 AI 辅助工作需要按课程要求声明
   - 项目中的 AI 贡献需要记录和说明

3. **及时更新**
   - 当获得新的课程材料时，更新相应的 markdown 文件
   - 保持 `sources/manifest.md` 的文件清单同步
   - 项目规格书发布后立即更新 `project/important/STATUS.md`

4. **语言支持**
   - 支持中文和英文交互
   - 技术术语保留英文以保持准确性
   - 根据用户偏好自动调整回复语言
