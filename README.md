# AIH-Project-SKILLS-and-Resources

PolyU AIH5571 课程学习资源和 AI Skills 集合

## 📚 项目简介

本仓库包含 **AIH5571: Introduction to Generative AI and Its Applications** 课程的学习辅助工具和资源。

## 🗂️ 仓库结构

### AIH_5571/
包含课程相关的 Claude Code Skills 和学习资源

- **[aih5571-course-project-assistant](AIH_5571/aih5571-course-project-assistant/)** - 课程和项目智能助手 Skill
  - 课程内容管理和复习
  - 小组项目跟踪和评估
  - 学术引用验证
  - 进度和待办事项管理

详细说明请查看各子目录的 README 文档。

## 🎯 适用对象

- AIH5571 课程学生
- 对生成式 AI 课程管理感兴趣的学习者
- 需要学术项目管理工具的研究者

## 🚀 快速开始

### 使用 Claude Code Skill

1. Clone 本仓库到本地
2. 将 `AIH_5571/aih5571-course-project-assistant` 目录放入 Claude Code 的 skills 目录
3. 在对话中提及 AIH5571 相关内容时自动激活

### 使用 ChatGPT 或其他 AI

大多数支持自定义知识库的 AI 助手（如 ChatGPT、Kimi）都可以使用本项目。

✅ **课程内容组织** - 结构化的课程资料和笔记管理
